# MiniSocial – Coding Assignment 1

Eeli Tavaststjerna – Social Computing 2026–2027, University of Oulu.

Added features: Unanswered filter, anonymous discussions and a weekly reply goal. Developed with ChatGPT assistance.

## Run on Windows

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Open http://127.0.0.1:8080 in your browser.
